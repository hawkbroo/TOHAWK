# TOHAWK — готовая сборка для GitHub Pages

Загрузите в корень репозитория всё содержимое этой папки: index.html, styles.css, appearance.css, script.js, img и works. README.md и .nojekyll тоже можно загрузить.

Не загружайте саму папку TOHAWK-GitHub как вложенную: index.html должен находиться прямо в корне репозитория.

Все шесть примеров работ находятся внутри works. Пути относительные: сборка подходит для репозитория с любым названием.

Развёртывание: Settings → Pages → Deploy from a branch → main → / (root) → Save.

Светлая и тёмная темы, заставка и подсветка курсора включены.

Это публичная статическая сборка. Локальные серверы, админские инструменты, документы заказчиков и резервные копии сюда не включены. Внешние сервисы и удалённые изображения в примерах работ используют прежние адреса.
